# 🏠 BLESS PG — Responsive Booking Website

A responsive website for a premium **PG / Hostel near Amity University Mumbai**, with online booking, gallery, pricing, and facilities preview.

---

## 🚀 Features

- Responsive UI (Mobile + Desktop)
- Tailwind CSS + Smooth Animations
- Online Booking Form (Popup Modal)
- Facilities & Room Pricing Section
- Image Gallery with Lightbox Preview
- Clean Modern Glass UI

---

## 🛠️ Tech Stack

| Tech | Usage |
|------|-------|
| **HTML5** | Page Structure |
| **Tailwind CSS** | Styling |
| **JavaScript** | Interactions & Popups |
| **AOS Library** | Page Animations |
